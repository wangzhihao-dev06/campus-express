# 截图清单

> 面试官只会看 README 和你点的链接，图比字有用得多。建议按下面的顺序截，每张都让**数据看着是真的**（有余额、有订单、有时间）。

## 必须截的 8 张

| 文件名 | 截什么 | 要点 |
|---|---|---|
| `01-student-parcel.png` | 学生端「我的包裹」列表 | 至少 3 条包裹，状态不同（未到站 / 已到站 / 滞留），已到站的显示取件码和货架位 |
| `02-student-order.png` | 学生端「代取订单」 | 一条进行中、一条已完成，能看到金额和小费 |
| `03-student-address.png` | 收货地址管理 | 2~3 个地址，一个标着「默认」 |
| `04-rider-hall.png` | 骑手端「抢单大厅」 | 列表里有多条待抢单，显示距离/体积/费用 |
| `05-rider-stat.png` | 骑手端「收益统计」 | 今日收益、累计收益、完成单数都有数字 |
| `06-admin-dashboard.png` | 管理端数据看板 | **最重要的一张**，6 张图表都要在同一屏能看到 |
| `07-admin-inbound.png` | 管理端「包裹入库」 | 填单号点入库后生成了取件码，或入库成功提示 |
| `08-miniprogram.png` | 微信小程序学生端首页 | 用开发者工具截图，选择手机尺寸，别截到工具栏 |

## 截图技巧

- 用浏览器 1280×800 以上窗口，**不要缩放页面**
- 数据要真实：先跑一遍「入库 → 下单 → 抢单 → 送达 → 确认收货」，让订单有时间戳和金额
- 深色模式的截图更好看，但要统一（8 张要么都浅色要么都深色）
- 别截到浏览器书签栏和一堆标签页，用 F11 全屏或裁剪掉
- 图片压到 300KB 以内（用 TinyPNG），太大 GitHub 加载慢
