## 截图技巧

- 浏览器窗口 1280×800 以上，**不要缩放页面**
- 数据要真实：先跑一遍「入库 → 下单 → 抢单 → 送达 → 确认收货」，让订单有时间戳和金额
- 深色浅色要统一（11 张要么都浅色要么都深色），混着放很乱
- 别截到书签栏和一堆标签页，用 F11 全屏或裁掉
- 压到 300KB 以内（TinyPNG），太大 GitHub 加载慢
