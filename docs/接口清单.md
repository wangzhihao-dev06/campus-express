# 接口清单

共 **46 个 REST 接口**，按角色分组。除标注「免登录」的接口外，均需在请求头携带对应身份的 JWT。

| 身份 | 请求头 | 密钥配置项 |
|---|---|---|
| 学生 | `authentication` | `campus.jwt.user-secret-key` |
| 骑手 | `rider-token` | `campus.jwt.rider-secret-key` |
| 管理员 | `token` | `campus.jwt.admin-secret-key` |

统一响应结构：`{ code, msg, data }`，`code = 0` 表示成功，非 0 表示业务失败（由全局异常处理器统一包装）。

## 公共

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| POST | `/auth/login` | 统一登录，按「管理员用户名 → 学生手机号 → 骑手手机号」识别身份，返回 `role`、`token`、`redirect` | 免登录 |
| GET | `/` | 根路径重定向到登录页 | 免登录 |
| GET | `/user/station/list` | 驿站列表 | 免登录 |
| GET | `/user/notice/list` | 公告列表 | 免登录 |

## 学生端 `/user`

### 账号

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/user/login` | 手机号 + 密码登录 | 
| POST | `/user/register` | 注册（手机号唯一性校验） |
| GET | `/user/info` | 获取个人信息（余额、学号、状态） |
| PUT | `/user/info` | 修改资料（仅允许改昵称与头像，其余字段服务端强制置空防越权） |

### 包裹

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/user/parcel/list` | 我的包裹列表，支持按状态筛选 |
| GET | `/user/parcel/{id}` | 包裹详情（取件码、货架位、入库时间） |
| POST | `/user/parcel/add` | 自助录入快递单号（快递未到站时先报单号） |

### 代取订单

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/user/order/submit` | 提交代取申请（校验余额、地址归属、重复下单，扣减余额） |
| GET | `/user/order/list` | 我的订单列表 |
| GET | `/user/order/{id}` | 订单详情 |
| PUT | `/user/order/cancel/{id}` | 取消订单（仅待接单状态可取消，原路退款） |
| PUT | `/user/order/confirm/{id}` | 确认收货（结算骑手收益） |
| POST | `/user/order/review` | 评价订单（调整骑手信誉分） |

### 收货地址

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/user/address/list` | 地址列表 |
| GET | `/user/address/default` | 默认地址 |
| GET | `/user/address/{id}` | 地址详情 |
| POST | `/user/address` | 新增地址 |
| PUT | `/user/address` | 修改地址 |
| DELETE | `/user/address/{id}` | 删除地址 |
| PUT | `/user/address/default/{id}` | 设为默认地址 |

## 骑手端 `/rider`

## 管理端 `/admin`

### 账号与看板

| 方法 | 路径 | 说明 |
|---|---|---|

| POST | `/admin/shelf` | 新增货架 |

## 说明

管理端的数据范围由 `currentStationId()` 控制：系统管理员（`role = 2`）返回 `null` 表示不限驿站，驿站管理员返回自己的 `stationId`，包裹查询、入库、订单列表均据此过滤，避免跨驿站越权。
