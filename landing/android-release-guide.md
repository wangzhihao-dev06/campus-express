# 青年驿站 Android 下载更新说明

学生端与骑手端共用一个 APK。宣传页在 HTTP/HTTPS 下每次打开或刷新都会重新请求同目录的 `android-release.json`。直接双击 HTML 时，浏览器可能禁止读取清单，应使用网页预览。

发布完整 APK 时：

1. 构建并签名，确认包名和签名沿用旧版，且 `versionCode` 递增。真机验证覆盖安装及登录。
2. 以新文件名上传 APK 到宣传页所在目录，例如 `youth-station-android-1.2.7.apk`。通过网页地址下载，确认文件可用并核对 SHA-256。
3. 最后替换 `android-release.json`，更新 `version`（如 `1.2.7`）、`apk`（同目录 APK 文件名）和 `sha256`（文件的 SHA-256）。如有 CDN 缓存，确保清单不会被长期缓存。
4. 刷新宣传页，确认学生和骑手下载入口显示同一新版。新版有问题时，把清单指回仍保留的上一版 APK。

只推送 `.wgt` 热更新时，不改此清单。清单不可读取或格式无效时，页面会回退到 1.2.6 测试包链接，因此不要移除该回退文件。`sha256` 用于发布时人工核验，网页不会自动下载 APK 来校验。
